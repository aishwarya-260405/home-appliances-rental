# Home Appliances Rental System

A web-based application developed to simplify the process of renting home appliances, with separate functionality for users and sellers.

## Features

- User and seller login & registration
- Browse and manage appliance listings
- Rental request management
- Request tracking
- Backend database connectivity

## Tech Stack

- Node.js
- Express.js
- SQLite
- EJS
- JavaScript

## Project Overview

The application provides a platform where users can browse available home appliances and submit rental requests, while sellers can manage appliance listings and rental-related requests.
